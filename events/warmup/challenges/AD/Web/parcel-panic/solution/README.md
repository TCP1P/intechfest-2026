## Summary

The parcel lookup joins the supplied name to `/srv/parcels` without checking the
resolved path. A relative traversal reaches the relay-managed `/shared/flag`
file. Reading that file returns the flag for the current A&D round.

## Player inputs

Players receive the public description, an opposing service URL, and their own
rsctf-generated BYOC setup. There is no downloadable handout. The normal API
advertises `GET /parcel?name=manifest.txt`, and that record identifies
`/srv/parcels` as the depot root.

## Walkthrough

1. Request `/` and then `/parcel?name=manifest.txt`. The service returns a
   dispatch record with `depot_root=/srv/parcels`, proving that the `name`
   parameter selects a filesystem entry below that directory.
2. Try a relative parent segment. The service rejects an absolute
   `/shared/flag` name, but it accepts `..` components.
3. From `/srv/parcels`, two parent segments reach `/`; appending `shared/flag`
   therefore selects the BYOC relay's current flag file.
4. Request
   `/parcel?name=..%2F..%2Fshared%2Fflag`. The response is the current
   `flag{...}` value, which can be submitted through the normal A&D flow.

## Why it works

Author implementation detail: the service checks that the supplied name is
relative, then opens `parcel_root / name` directly. It deliberately does not
resolve the result and enforce containment beneath `/srv/parcels`. Linux path
resolution follows the two `..` components into `/shared/flag`.

The checker does not depend on this vulnerability. It proves knowledge of the
current flag with `SHA-256("parcel-panic:v1\\0" || flag)` in the
`X-Vault-Proof` header and reads the exact value through `/vault`. This lets a
team patch traversal while preserving legitimate flag verification. Both the
service and checker use the flag supplied for the current round; the service
reads its file on every vault or traversal request, so atomic rotation does not
require a restart.

## Solver

[`solve.py`](solve.py) performs the single encoded traversal with the Python
standard library and validates rsctf's A&D flag grammar.

```sh

```
