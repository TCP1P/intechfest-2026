RSCTF adaptation changes by dimasma0305, 2026:

- changed the default internal framebuffer from 160x100 to 256x128;
- renamed user-facing builds and windows to Minions in 32K;
- added an HTTPS RSCTF capability exchange and pinned arena bootstrap;
- added a demand-driven match supervisor and RSCTF result adapter;
- bumped the wire format to protocol v13;
- added server-authoritative Banana Confirmed objectives with killer-only
  confirmation, victim-only denial, bounded lifetime/state, and result events;
- added confirmation HUD/markers, persistent final standings, reusable secure
  lobby sessions, and a collision-aware reference network bot;
- retained the applicable licenses and attribution with the player build.

The arena foundation, maps, models, audio, authoritative networking, replay
logic, and legacy bot profiles originate from the upstream challenge. Banana
Confirmed and the objective-aware solution are adaptation changes.
