# Trailer sound sources

These samples are extracted unchanged from `osu.Game.Resources.dll` produced by
the pinned osu!lazer source build used for the Rythme client capture. They are
author-side trailer assets and are not copied into the player release.

The filenames retain their original resource paths in flattened form, for
example:

- `Menu-osu-logo-select.wav`
- `Intro-welcome.mp3`
- `Multiplayer-countdown-tick.wav`
- `Gameplay-Argon-normal-hitnormal.wav`

This keeps the teaser's UI and gameplay audio consistent with the client shown
on screen rather than substituting generated sound effects.
